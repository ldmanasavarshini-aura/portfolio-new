# Manasavarshini L.D. | Portfolio Website

A personal portfolio website with a clean, professional design and smooth animations.

**Live site:** https://ldmanasavarshini-aura.github.io/Portfolio_new/

## About

I am a B.Tech Information Technology student at Sri Shakthi Institute of Engineering and Technology, Coimbatore (2025–2029). I build practical AI apps, especially in healthcare. This website shows my skills, projects and journey.

## Features

- Fixed sidebar with a menu that follows the section you are reading
- Smooth page-load animation and drawing underlines on headings
- Click-to-open project cards
- Contact buttons for GitHub, LinkedIn and Email
- "Copy email address" button
- Works on phones, tablets and laptops
- Automatic dark mode and light mode
- Respects the "reduce motion" setting on devices

## Built With

- HTML
- CSS
- JavaScript (plain, no libraries)

The whole site is one file: `index.html`.

## Run on Your Computer

1. Download or clone this repository.
2. Open `index.html` in any browser.

That's it. No install is needed.

## Put It Online (GitHub Pages)

1. Upload `index.html` to a public repository named `portfolio`.
2. Go to **Settings**, then **Pages**.
3. Choose branch **main** and folder **/ (root)**, then click **Save**.
4. Wait 1 to 2 minutes. Your site will be live.
